# Student Expense Tracker and Budget Analyzer

## 1. Project Overview

Student Expense Tracker and Budget Analyzer is a menu-driven Python application designed to help students record, manage, search, and analyze their daily expenses.

The project provides expense management, expense analytics, and monthly budget management features. It uses Python functions, lists, dictionaries, loops, conditional statements, string operations, and basic algorithms.

The project is developed as a syllabus-aligned project for CSE1021 - Introduction to Problem Solving and Programming.

---

## 2. Problem Statement

Students often have difficulty keeping track of their daily spending and understanding where their money is being used.

This project provides a simple command-line system where users can record expenses, view and modify them, search for particular expenses, calculate total spending, analyze expenses by category, identify the highest expense, and compare monthly spending with a budget.

---

## 3. Objectives

The main objectives of the project are:

- To provide a simple system for recording student expenses.
- To allow users to view, update, and delete expense records.
- To provide search functionality for expenses.
- To calculate total expenses.
- To summarize expenses according to categories.
- To identify the highest individual expense.
- To calculate monthly expenses.
- To allow users to set a monthly budget.
- To display whether spending is within or above the budget.
- To apply fundamental Python programming concepts in a practical project.

---

## 4. Features

### Expense Management

- Add a new expense
- View all expenses
- Update an existing expense
- Delete an expense
- Search expenses by category, description, or date

### Expense Analytics

- Calculate total expenses
- Count expenses
- Generate category-wise expense summary
- Find the highest expense
- Calculate expenses for a particular month

### Budget Management

- Set a monthly budget
- Calculate remaining budget
- Check monthly budget status
- Detect when the budget has been exceeded

### Input Validation

- Validate expense amount
- Validate category
- Validate basic date format
- Validate expense ID
