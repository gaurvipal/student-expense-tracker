# Project Statement

## Project Title

Student Expense Tracker and Budget Analyzer

---

## Problem Statement

Students often need to keep track of their daily expenses and understand how their money is being spent.

The Student Expense Tracker and Budget Analyzer provides a simple menu-driven Python application for recording and managing expenses. It allows users to add, view, update, delete, and search expense records. It also provides basic expense analysis and monthly budget management.

---

## Project Scope

The project focuses on developing a command-line expense management application using fundamental Python programming concepts.

The scope includes:

- Recording student expenses
- Viewing expense records
- Updating expense information
- Deleting expense records
- Searching for expenses
- Calculating total expenses
- Generating category-wise summaries
- Finding the highest expense
- Calculating monthly expenses
- Setting monthly budgets
- Checking budget status
- Validating user input

The current version stores data in memory while the program is running.

---

## Target Users

The primary target users are:

- College students
- Students who want to track daily spending
- Users who need a simple personal expense management system

---

## High-Level Features

The major features of the project are:

1. Expense Management
   - Add expenses
   - View expenses
   - Update expenses
   - Delete expenses
   - Search expenses

2. Expense Analytics
   - Calculate total expenses
   - Generate category summaries
   - Find the highest expense
   - Calculate monthly expenses

3. Budget Management
   - Set monthly budget
   - Check budget status
   - Identify remaining or exceeded budget

4. Input Validation
   - Validate amounts
   - Validate categories
   - Validate dates
   - Validate expense IDs

---

## Expected Outcome

The expected outcome is a functional, modular Python application that demonstrates problem-solving and programming concepts through a practical expense-management problem.

The project also demonstrates the use of functions, lists, dictionaries, loops, conditional statements, searching, summation, validation, and modular program design.
